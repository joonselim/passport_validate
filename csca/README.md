# csca/

Put country certificates (CSCA) here. The server loads them at startup.

Supported files: `.cer`, `.crt`, `.der`, `.pem` (certificates) and `.ml` (ICAO master list).

Easiest source: the German BSI Master List.
https://www.bsi.bund.de/SharedDocs/Downloads/DE/BSI/ElekAusweise/CSCA/GermanMasterList.html

Certificate files in this folder are not committed to git.
